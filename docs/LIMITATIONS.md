# Limitations

- Educational, idealized 24 V DC model only; not an electrical design or safety tool.
- One sheet and a deliberately small component catalog.
- Project JSON is specific to this application; no `.CAD` import or compatibility claim.
- Symbols are independently authored and are not claimed to be standards-certified artwork.
- Browser recovery is a single best-effort local record, not a durable backup.
- Downloaded files are not confirmed saved until the user verifies them.
- Runtime traces, live handles, and undo history are not stored in project files.
- Production offline behavior requires a successful online load at the same origin first.
- Chromium is the automated browser target. Other browsers, mobile devices, screen readers, native file permissions, physical printing, and large-project performance require manual evaluation.
- A passing test suite does not establish usability, accessibility, electrical correctness outside the supported model, deployment safety, or certification.

Keep independent backups of important project files and obtain qualified engineering review for real electrical work.
